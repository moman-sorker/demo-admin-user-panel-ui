// FEATURES

Everything you need, out of the box.

Eleven battle-tested features ready to plug into any backend.

Role-Based Access

Viewer · Editor · Superadmin — enforced on both UI and API level.

Two-Factor Auth

TOTP-based 2FA with QR setup. Works with Google Authenticator, Authy, 1Password.

Support Tickets

Threaded conversations between users and admins with status workflow.

Notifications

In-app inbox + optional real email via SMTP. Broadcast to all users.

Search · Filter · Pagination

Server-side everything. Scales to thousands of rows without breaking a sweat.

Live Activity Log

Every action is timestamped. See who did what, when, and why.

Avatar Upload

User profile pictures with instant preview and file validation.

Cross-Device Theme

Dark or light — synced to your account, so it follows you everywhere.

JSON Portable

Zero DB required. Just JSON files. Swap for Postgres/Mongo when ready.

// ROLES

Built-in access tiers.

Granular permissions. Zero setup. Just pick a role.

👁️

Viewer

Read-only access to dashboards, users and tickets.

  • ✅ View all dashboards
  • ✅ Read users & tickets
  • ✅ See activity log
  • ❌ Create or edit anything
  • ❌ Delete or broadcast
✏️

Editor

Daily driver for admins. Create, edit, reply, manage.

  • ✅ Everything Viewer can do
  • ✅ Create & edit users
  • ✅ Reply tickets & change status
  • ✅ Bulk activate / disable
  • ❌ Delete or manage admins
POPULAR
👑

Superadmin

Full control. Manage admins, delete, broadcast.

  • ✅ Everything Editor can do
  • ✅ Create / edit / delete admins
  • ✅ Delete users & bulk delete
  • ✅ Broadcast notifications
  • ✅ Change any role
